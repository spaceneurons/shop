# LUMI

Минималистичный интернет-магазин одежды. Только HTML, CSS и JavaScript — без сборки, поэтому сайт открывается на GitHub Pages.

Главная повторяет макет: шапка, герой, категории, новинки, промо, блок «для каждого поколения» и подвал. Фотографии лежат в папке `images` и называются `image 12.png` … `image 77.png`. Сайт раздаёт эти файлы по карточкам, категориям и баннерам в случайном, но постоянном порядке.

Корзина, избранное и профиль сохраняются в браузере. Оформление заказа ничего не списывает и никуда не отправляет.

## Локально

Откройте `index.html` или поднимите папку как статику:

```bash
python3 -m http.server 43123
```

Адрес: [http://127.0.0.1:43123](http://127.0.0.1:43123).

## GitHub Pages

В репозитории: Settings → Pages → Branch `main`, папка `/` (root). Файл `.nojekyll` уже лежит в корне, ссылки относительные.

После публикации витрина будет здесь: [https://spaceneurons.github.io/shop/](https://spaceneurons.github.io/shop/).

## Что есть

- Одинаковые боковые поля у шапки, героя, категорий, карточек, промо и подвала. В блоке новинок четыре карточки в ряд
- Каталог с фильтрами по разделам, Salé и сортировкой
- Карточка вещи с выбором размера
- Корзина, избранное, поиск и локальный профиль
- Слайды героя и промо, наведение на карточки, тосты
