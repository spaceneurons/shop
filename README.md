# LUMI

Минималистичный интернет-магазин одежды. Главная повторяет макет LUMI: шапка, герой, категории, новинки, промо, блок «для каждого поколения» и подвал. На месте фотографий — графические заглушки.

Корзина, избранное и профиль сохраняются в браузере. Оформление заказа ничего не списывает и никуда не отправляет.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Что есть

- Главная в композиции макета 1024px
- Каталог с фильтрами по разделам, Salé и сортировкой
- Карточка вещи с выбором размера
- Корзина, избранное, поиск и локальный профиль
- Слайды героя и промо, наведение на карточки, тосты
